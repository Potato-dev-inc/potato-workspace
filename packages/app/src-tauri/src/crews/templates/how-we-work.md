# How work is routed (plain words)

Always
- Pass my exact words along with the clear version.
- Tell me which way it went. I can change it.
- Cheapest role that can finish in one go.

Ask me first
- Pushing, publishing, deleting, or anything with logins or money.

Scout first (read-only, short summary)
- Any task where it is not yet clear which files matter.

Easy -> worker-easy
- One area, a known pattern, a small change to copy or style.

Medium -> worker-medium
- Several files in one layer. If it stalls, it goes to the hard worker.

Hard -> worker-hard
- Many files, an unknown cause, or work across layers.

Check -> checker
- Every finished branch is checked before I merge it.
