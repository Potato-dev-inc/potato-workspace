program name you type to start it, and its web address. They were used to add these entries to the Agent Store
catalog: OpenClaw, Hermes Agent, jcode, Autohand Code, Codebuff. Each vendor's licence was read from the vendor's own
GitHub page. No Orca code, text, images or settings were copied.
