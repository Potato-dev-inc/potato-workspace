Material Icon Theme (file and folder icons)

The icons beside file and folder names (the Files list, file tabs, search results, Outputs and Changes, and the @ file
picker) are a selection of the SVG icons of the Material Icon Theme for VS Code by Philipp Kief and contributors,
https://github.com/material-extensions/vscode-material-icon-theme (tag v5.40.0, commit 045291ff033062a25441dd297fd51546326866f2).
The picture files are copied unchanged (white space removed). The rules that pick an icon by file name, extension or
folder name are ported from the theme's fileIcons and folderIcons lists.
